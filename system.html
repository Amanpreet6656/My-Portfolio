02 / ENGINEERING METHODOLOGY & PHILOSOPHY

Offline-First as Fundamental Architecture

I architect software on the assumption that network connectivity is an unreliable, ephemeral luxury. Critical business data and user mutations must commit immediately to local persistence layers (Web Storage API or IndexedDB) prior to network transmission. This design ensures that systems deployed in remote construction sites, disaster-prone regions, or embedded industrial targets continue operating with deterministic integrity during complete network isolation.

Raw Performance Over Bloated Abstractions

Modern frontend engineering has accumulated layers of redundant abstractions: virtual DOM diffing, multi-megabyte bundle dependencies, and opaque runtime overhead. I build production web applications utilizing Vanilla JavaScript (ES6+) directly against native Web APIs. This reduces application payloads to minimal footprints, achieves wire-speed execution, and ensures predictable garbage collection cycles.

In systems-level C++, compile-time template metaprogramming replaces runtime dynamic polymorphism. Virtual dispatch pointer dereferences are eliminated from the critical computational path, and memory buffers are strictly aligned to 64-byte hardware cache boundaries.

Custom Mathematics from First Principles

Rather than importing heavy graphics libraries (such as Three.js or Babylon.js), I implement spatial mathematics, 3D perspective projection matrices, orthonormal camera basis transformations, and N-body Coulomb anti-gravity physics from first principles. Writing linear algebra directly yields total transparency, zero dependency vulnerabilities, and complete control over computational efficiency.

Discipline Formed Through Martial Arts

A rigorous, disciplined approach to code is directly mirrored by continuous martial arts training in Taekwondo and Boxing. The physical demands of combat sports - kinetic economy of motion, spatial awareness, mental composure under high stress, and relentless technical repetition - translate seamlessly into writing fault-tolerant systems software. Code, like striking technique, must possess zero excess movement, precise execution, and unyielding structural integrity.

03 / ACTIVE RESEARCH VECTORS

WebAssembly via the Emscripten Toolchain

Actively researching the compilation of modular C++ machine learning kernels into WebAssembly (WASM) using Emscripten. The goal is to deploy the InferC forward pass directly within modern browsers, executing cache-optimized tensor arithmetic at near-native binary speeds without requiring server round-trips or specialized runtime installations.

Unreal Engine 5 Real-Time Rendering Pipelines

Investigating the intersection between low-level CPU spatial math and GPU shader execution architectures within Unreal Engine 5. Focus areas include analyzing how virtualized microgeometry systems (Nanite) and real-time indirect illumination (Lumen) correlate with the custom perspective projection, depth-sorting, and force-directed algorithms implemented across my web graphics projects.
