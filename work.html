PROJECT 01 / SYSTEMS ENGINEERING

01

InferC

Header-Only C++17 Feed-Forward Neural Network Inference Library

A standalone, header-only neural network inference library written in ISO C++17 using only the C++ Standard Library (no BLAS, Eigen, or external tensor frameworks). Designed to study CPU cache locality, numerical stability, and safe binary model deserialization.

inferc::Tensor manages contiguous row-major std::vector<float> storage with integer overflow checks on dimensions, strong exception guarantees during resize and load_weights, and runtime pointer identity checks around __restrict__ qualifiers to keep in-place operations free of undefined behavior. Dense forward passes use an i-k-j loop interchange with 4-way K-unrolling and fused bias accumulation (gemm_bias), paired with branchless ReLU and overflow-guarded Softmax.

Weights are exported by a companion Python script into a validated little-endian binary format (INFC magic header, protocol version, endianness marker, dimension checks, and std::isfinite validation). Verified on GitHub Actions across both g++ and clang++ with AddressSanitizer and UndefinedBehaviorSanitizer.

PROJECT 02 / JAPANESE LANGUAGE TOOLS

02

Nihongo Syntax Matrix & Smart Kanji Analyzer

Client-Side Japanese Verb Conjugation, Calendar Grammar & Kanji Breakdown Tools

Nihongo Syntax Matrix is a deterministic, offline-capable Japanese grammar explorer implemented in Vanilla JavaScript (ES6+). It classifies verbs into Godan, Ichidan, Suru, and Kuru paradigms (including godan -iru/-eru exceptions, keigo stems, and onbin euphonic mutations), generates plain and polite conjugations with Hepburn romanization, and models irregular Japanese calendar readings alongside temporal particle rules (に, から, まで).

Smart Kanji Analyzer isolates unique CJK ideographs from user-entered Japanese sentences via Unicode character-range evaluation (using spread-operator code-point iteration and Set deduplication), fetches readings, stroke counts, and JLPT levels from kanjiapi.dev with local caching and offline fallback entries, and builds interactive review flashcards via a pub-sub AppState store.

Both projects run directly in the browser without frontend UI frameworks or backend servers, and include automated Node.js verification tests covering conjugation rules and character extraction.

PROJECT 03 / GEOPHYSICAL TELEMETRY

03

Japan Seismic & Weather Dashboard

Client-Side Seismic, Meteorological & Preparedness Dashboard for Japan

A client-side monitoring dashboard built with HTML5, CSS3, Vanilla JavaScript, and Leaflet 1.9.4. The platform aggregates real-time USGS earthquake GeoJSON feeds, Open-Meteo meteorological forecasts (targeting the jma_seamless model), Wolfx JMA Earthquake Early Warning WebSocket/HTTP streams, and OpenStreetMap Nominatim geocoding.

For each USGS earthquake event, the application computes estimated JMA instrumental Shindo intensity using the Midorikawa et al. (1999) attenuation relationship alongside approximate P-wave and S-wave transit times. Weather telemetry evaluates heatstroke risk using the Ministry of the Environment simplified WBGT formula.

Interactive cartography runs through Leaflet using Esri ArcGIS World Dark Gray raster tiles (with OpenStreetMap tile fallback) and polyline overlays for major subduction zones. Watchlist locations and Tokyo BCP 72-hour preparedness checklist states persist in browser localStorage.

PROJECT 04 / LOCAL-FIRST UTILITY

04

BuildLedger Pro

Bilingual Offline-Capable Construction Payroll & Attendance Tracker

A client-side payroll and attendance tracking web tool built for construction supervisors working in low-connectivity field environments. Built as a standalone HTML5 application styled with Tailwind CSS (via CDN) and FontAwesome icons, driven by Vanilla ES6+ JavaScript.

All worker profiles, daily attendance states (full day 1.0, half day 0.5, absent 0.0), and cash advance deductions are persisted synchronously in browser localStorage. Includes dynamic English/Hindi localization, dark/light theme toggling, and RFC 4180 CSV payroll export.
