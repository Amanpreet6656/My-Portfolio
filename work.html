PROJECT 01 / NATURAL LANGUAGE SYSTEMS

01

Smart Kanji Analyzer & Nihongo Syntax Matrix

Offline-First Japanese Morphological & Temporal Syntax Engine

A full-stack linguistic platform engineered with vanilla JavaScript for analyzing Japanese temporal syntax and semantic structures. The parsing pipeline tokenizes unstructured text via Kuromoji.js (utilizing the complete IPA dictionary compiled into binary format), resolves kanji stroke and radical metadata through kanjiapi.dev REST endpoints, and computes real-time phonetic transliteration into Hepburn romaji.

The temporal syntax parser decomposes complex Japanese verb conjugations, classifying grammatical time aspects (aspectual auxiliaries, past/non-past markers, and relative temporal clauses). All dictionary lookups and API responses are committed to a deterministic Web Storage API cache layer, allowing the engine to execute completely offline after first-time dictionary hydration.

Eliminating framework abstraction layers guarantees sub-millisecond tokenization latency even across extensive paragraphs of authentic Japanese text.

PROJECT 02 / SYSTEMS ENGINEERING

02

InferC

C++17 Machine Learning Inference Engine for Edge Deployment

A standalone, dependency-free neural network inference runtime engineered in ISO C++17. Designed specifically for deployment on edge and embedded microcontrollers where dynamic language runtimes, Python interpreters, and CUDA GPU toolchains cannot be provisioned.

Matrix transformation kernels are hand-crafted for high CPU cache locality. Contiguous memory buffers are strictly aligned to 64-byte boundaries (matching modern x86_64 and ARM L1/L2 cache lines) to prevent false sharing and minimize cache misses during intensive General Matrix Multiply (GEMM) sweeps. Compile-time template metaprogramming eliminates virtual dispatch overhead in the inner inference loops.

The forward computational pass supports fully connected dense layers, Rectified Linear Unit (ReLU) activations, and numerical softmax normalization. Model parameter weights are imported via a custom zero-copy binary serialization format.

BuildLedger Pro

Local-First Construction Payroll & Attendance Manager

The state management engine handles tradesperson rosters, hourly rate matrices, overtime brackets, and aggregate payroll reporting. Every state transition is written synchronously to local persistent storage, providing immediate crash resilience against battery depletion or browser termination.

The user interface eschews CSS component libraries in favor of sharp, high-contrast, touch-optimized layouts engineered for high visibility on ruggedized field tablets in direct sunlight.

PROJECT 04 / GEOPHYSICAL TELEMETRY

04

Japan Seismic & Weather Dashboard

Offline-First Telemetry Application Combining JMA Seismic Data & Open-Meteo APIs

A high-frequency geophysical telemetry web application tracking real-time seismic events and atmospheric parameters across the Japanese archipelago. The system combines open seismic data feeds from the Japan Meteorological Agency (JMA) with atmospheric forecasts from the Open-Meteo REST API.

Engineered for critical situational awareness during infrastructure disruptions, the application implements an offline-first caching pipeline. All fetched seismic intensity matrices (measuring Japanese seismic intensity shindo scales 1 through 7) and weather parameters are cached locally via the Web Storage API and IndexedDB. Even when telecommunication towers fail, the application continues to display cached seismic fault lines, localized warning thresholds, and recent historical seismicity.

Spatial cartography is rendered via native SVG coordinates and HTML5 canvas projections without external map tile dependencies (such as Mapbox or Google Maps), reducing initial network payload by over 90% and running at 60 FPS on low-power devices.
